Completeness and Relevance Evaluation Guide

Introduction

This guide explains how to evaluate AI-generated responses based on completeness, relevance, missing information, and instruction following.

1. Completeness

Completeness measures whether an AI response includes all the important information requested by the user.

Questions to ask:

* Did the response address every requested point?
* Did it include all required categories or examples?
* Is any important information missing?

Example:

User requests three benefits of exercise, but the AI provides only two.

Evaluation: The response is relevant but incomplete.

2. Relevance

Relevance measures how closely an AI response addresses the user’s actual question.

Questions to ask:

* Does the response answer the question?
* Is the information related to the user’s request?
* Does it avoid unrelated details?

Example:

User asks about the benefits of drinking water, but the AI explains the history of bottled water.

Evaluation: The response is poorly relevant.

3. Identifying Missing Information

When evaluating an incomplete response:

1. Identify the user’s specific requirements.
2. Compare the requirements with the response.
3. Identify exactly which requested information is missing.
4. Explain the omission clearly and objectively.

Avoid vague feedback such as “The answer is bad.” State what is missing and why it matters.

4. Recognizing Unnecessary Information

A response can contain all requested information while also including unnecessary details.

Consider:

* Whether extra information helps answer the question.
* Whether it makes the response longer than requested.
* Whether it violates instructions about brevity or simplicity.

More information does not automatically mean greater completeness.

5. Ranking AI Responses

When comparing two responses:

1. Check whether both answer the user’s actual question.
2. Check whether each response includes all requested information.
3. Evaluate whether each follows the user’s instructions.
4. Identify unnecessary details or missing information.
5. Rank the response that best satisfies the overall requirements.

6. Writing Professional Evaluator Feedback

Good evaluator feedback should:

* Identify the stronger response.
* Explain the specific reasons for the ranking.
* Mention missing information when relevant.
* Distinguish relevance from completeness.
* Avoid unsupported criticism.

Example:

“Response B ranks higher because it addresses all three requested categories. Response A is relevant but incomplete because it omits the requested sleep-related benefit.”

7. Important Evaluation Principles

* Relevant does not always mean complete.
* More information is not always better.
* Missing information should be identified specifically.
* Extra details should be assessed against the user’s instructions.
* Rankings should be based on the full set of requirements, not personal preference.

Conclusion

A good AI evaluator must determine whether a response answers the user’s question, includes all required information, and follows the stated instructions. These skills help produce fair, consistent, and evidence-based evaluations.
