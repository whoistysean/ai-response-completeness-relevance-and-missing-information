AI Response Completeness, Relevance and Missing Information Evaluation

Project Overview

This project demonstrates practical skills in evaluating AI-generated responses based on completeness, relevance, missing information, and instruction following.

It contains practical exercises designed to identify incomplete answers, recognize unnecessary information, and compare AI responses against user requirements.

Skills Demonstrated

* AI Response Evaluation
* Completeness Assessment
* Relevance Assessment
* Missing Information Detection
* Instruction Following
* Comparative Response Ranking
* Evaluator Feedback Writing

Evaluation Criteria

1. Completeness

Checks whether an AI response includes all important information requested by the user.

2. Relevance

Checks whether the response directly addresses the user’s question without unnecessary distractions.

3. Missing Information

Identifies specific requested details that an AI response has failed to include.

4. Instruction Following

Checks whether the response follows requirements such as length, simplicity, and the number of requested points.

Practical Exercises

* Exercise 1: Evaluating Completeness and Relevance
* Exercise 2: Identifying Missing Information
* Exercise 3: Comparing Responses Against Multiple Instructions
* Final Challenge: Ranking Responses Based on Evaluation Criteria

Learning Outcomes

Through this project, I practised:

* Identifying relevant but incomplete responses.
* Recognizing when an answer contains unnecessary information.
* Distinguishing completeness from simply providing more information.
* Ranking responses based on the user’s actual requirements.
* Writing clear and evidence-based evaluation feedback.

Project Note

All exercises are educational practice examples. They demonstrate AI evaluation skills and do not represent paid professional work or client assignments.
